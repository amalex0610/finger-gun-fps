## 🎮 人體工學大拇指射擊 (Pure Thumb Trigger)

回歸最自然純粹的「大拇指扣扳機」手感：
* 👉 **食指瞄準**：大拇指立起時進入 `⚡ READY` 上膛。
* 💥 **向下扣動大拇指**：主動下壓擊發（`FIRE!!`），扣下後進入消耗狀態。
* 🛡️ **重疊絕不走火**：大拇指貼著食指重疊時安靜瞄準，杜絕任何誤射！必須主動重新立起拇指才能打出下一發！
* ✌️ **雙指霰彈模式**：食指＋中指併攏，扇形 5 發大範圍覆蓋！
