## 🛸 4.0 全新震撼升級：巨型賽博母艦 BOSS 戰 (Cyber Dreadnought)

1. **👑 巨型太空巡洋母艦降臨**：
   * 累積擊殺滿 16 隻敵人後，全螢幕響起紅色空襲警報：`⚠️ WARNING: CYBER DREADNOUGHT BOSS ⚠️`！
   * 巨型戰列母艦遮天蔽日從天空上方緩慢降臨！
2. **🛡️ 多階段弱點部位破壞**：
   * **階段 1：左右浮游護盾翼 (L-Core & R-Core)**：
     左右各有一座旋轉能量核心（HP 8），此時中央主反應爐覆蓋無敵力場（`IMMUNE!`），玩家必須先轟碎兩翼！
   * **階段 2：中央超載弱點暴露 (Reactor Weakpoint)**：
     兩翼破壞後護盾瓦解，中央核心暴露出高溫橘紅弱點，射擊造成 **雙倍爆頭傷害 (CRITICAL!)**！
   * **階段 3：敵方能量彈幕防禦**：
     母艦會向玩家發射紅色能量光球，玩家可以用槍在空中精準打爆敵方子彈！
   * **階段 4：連環史詩大核爆**：
     擊破母艦引發連續 7 級全屏大爆炸、狂爆 +3000 分，並掉落大量的全息肉鴿晶片箱！
3. **🎁 固定 4 格微型肉鴿晶片槽**：
   * 晶片升級完全固定在左上角 4 個微型圖示中（`⚡`、`💥`、`⏱️`、`🛡️`），等級堆疊（Lv.1 ~ Lv.3），視野 100% 保持開闊！
